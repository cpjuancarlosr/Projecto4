# Universal Capture System (Google Apps Script + Sheets + Telegram)

This repository contains a production-ready universal capture and data management system using Google Apps Script as the backend, Google Sheets as the data lake, and Telegram + HTML capture interfaces as input channels.

## Contents
- `apps-script/`: Apps Script backend, Telegram webhook handler, query engine, and HTML capture UI.
- `docs/SETUP.md`: Schema, setup steps, and operational flow.

## Quick Start
1. Open `docs/SETUP.md` for complete setup instructions.
2. Deploy the Apps Script project as a Web App.
3. Connect Telegram via webhook and start capturing.
